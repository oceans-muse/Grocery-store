# 🏪 杂货铺

欢迎来到我的零散文件收纳站！这个仓库就像一个随手的“杂货铺”，用来存放各种临时、零碎、不成体系的文件、脚本、配置片段、学习笔记等。  
**目的**：避免在本地硬盘上到处散落，同时方便跨设备同步和快速查找。
